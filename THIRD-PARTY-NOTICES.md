# Third-party software

Portable downloads bundle Node.js 24.21.0. Its complete license and bundled
third-party notices are in `runtime/LICENSE`.

Application dependencies are installed from `package-lock.json`. Their license
files are preserved in `node_modules/`, including:

- React and React DOM — MIT
- Lucide React — ISC (icons include upstream notices)
- ssh2 — MIT
- asn1 — MIT
- bcrypt-pbkdf — BSD-3-Clause
- safer-buffer — MIT
- tweetnacl — Unlicense

The application is an independent community project, not an official OpenAI product.
